# Upstream proposals

Proposals for **other** projects, written here so they can be reviewed before
anything is posted externally.

**Nothing in this directory is sent anywhere.** No issue is opened, no PR is
opened, and no comment is posted from this repository to another project. The
external send is the owner's decision, not the plugin's, and it happens from a
different account with a different review.

## The rule

Every claim in these files carries the version, the exact command and the
output it produced, so a maintainer of the other project can reproduce it
without asking a question. If a claim cannot be reproduced, it does not go in
the file.

When one of these is sent, the file stays here as the record of what was asked
and what it was based on.
